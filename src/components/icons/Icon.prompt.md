Lucide icon wrapper — use for every icon so stroke weight and colour stay consistent.

```jsx
<Icon name="workflow" size={20} />
<Icon name="check" color="var(--accent)" label="Completado" />
```

- Inherits `currentColor`; set colour on the parent.
- Sizes: 14 dense tables, 16 default, 20 navigation, 24 feature rows.
